01 / The Concept

Search with a sense of direction.

A* combines the cost of the route already travelled with an estimate of the distance remaining.

What is the A* algorithm?

A* (pronounced “A-star”) is an informed search algorithm used to find a least-cost path from a starting point to a goal. It evaluates possible positions and prioritizes those that appear most promising.

Unlike an uninformed search that explores without estimating the remaining distance, A* uses a heuristic to guide its exploration. Its result depends on the cost model, heuristic, and search implementation.

f(n) = g(n) + h(n)
The evaluation function that guides A*

g(n) is the cost from the start to the current node.

h(n) estimates the remaining cost from the current node to the goal.

The three key ideas

g
Cost so far

Measures the known cost of reaching a position from the start.

h
Heuristic estimate

Provides a useful estimate of the remaining distance to the destination.

f
Estimated total cost

Combines the cost already paid with the estimated cost still to come.

For a four-direction grid with equal step costs, Manhattan distance is a suitable heuristic.

03 / Behind the Search

How A* finds the route.

The algorithm repeatedly selects a promising node and updates the best known routes to its neighbours.

01

Initialize

Start at the initial node and calculate its estimated total cost using g(n) + h(n).

02

Select

Choose the open node with the smallest estimated total cost.

03

Explore

Inspect valid neighbours, avoid walls, and update their best known costs and parent links.

04

Reconstruct

When the goal is reached, follow parent links backwards to reconstruct the path.

05 / Real-World Applications

Where does A* make a difference?

Search algorithms are useful whenever a system needs to move through a set of possible states.

🎮

Video Games

Helps non-player characters navigate maps, move around walls, and reach targets.

🤖

Robotics

Supports route planning for robots navigating environments with obstacles.

🗺️

Maps & Navigation

Illustrates how route planners search for low-cost routes through connected locations.

📦

Warehouse Systems

Can help plan movement for automated carts and robots around restricted areas.

🧩

Puzzle Solving

Searches possible states in puzzles using a heuristic to estimate distance from a solution.

🧠

Artificial Intelligence

Demonstrates informed search: using knowledge about the goal to guide decision-making.

THE BIG IDEA

Search intelligently, not blindly.

A* shows how combining the cost of past decisions with an estimate of future cost can guide a search toward a useful solution. The quality of its heuristic and the structure of the problem both matter.
