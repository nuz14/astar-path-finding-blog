🧭 A* Search on a Grid

A technical blog explaining how the A* search algorithm finds efficient paths on a grid while avoiding obstacles.

Introduction

A* (pronounced A-star) is a popular path-finding algorithm used to find an efficient route between a starting point and a destination.

It combines the actual distance already travelled with an estimated distance to the goal. This allows A* to search intelligently instead of checking every possible path.

Simple idea: A* chooses the path that looks most promising based on both the distance travelled and the estimated distance remaining.

Core Idea of A*

A* uses an evaluation function called f(n). It helps the algorithm decide which grid cell should be explored next.

f(n) = g(n) + h(n)

Meaning of the terms

  • g(n) — actual cost from the starting point to the current cell.
  • h(n) — estimated cost from the current cell to the goal.
  • f(n) — total estimated cost of the path.

How A* Works

1. Start

Begin from the starting cell.

2. Evaluate

Calculate the f, g and h values.

3. Choose

Select the cell with the lowest f value.

4. Reach Goal

Continue until the destination is reached.

Obstacles and Path Finding

A grid can contain obstacles that cannot be crossed. A* considers these obstacles while searching for a route.

Instead of moving through blocked cells, the algorithm explores other available cells and tries to find a valid path to the destination.

Manhattan Distance

When movement is restricted to horizontal and vertical directions, Manhattan distance can be used as the heuristic.

h(n) = |x₁ − x₂| + |y₁ − y₂|

It calculates the distance between two points by adding the horizontal and vertical differences.

Simple Example

Suppose the starting point is at (1,1) and the destination is at (4,5). 

h(n) = |1 - 4| + |1 - 5|

h(n) = 3 + 4

h(n) = 7

Therefore, the Manhattan distance between the two points is 7.

Applications of A*

  • 🎮 Video game path finding
  • 🤖 Robot navigation
  • 🗺️ Route planning
  • 🚗 Autonomous vehicle navigation
  • 📍 Grid-based navigation systems

Advantages

  • Finds efficient paths between two points.
  • Can work around obstacles.
  • Uses a heuristic to guide the search.
  • Usually explores fewer unnecessary paths than uninformed search.
  • Widely used in navigation and games.

Conclusion

A* is an important search algorithm for path finding and obstacle avoidance. By combining the actual cost with an estimated cost, it can efficiently search for a suitable path from a starting point to a destination.

Its use in games, robotics, navigation and intelligent systems shows how search algorithms can solve practical real-world problems.
