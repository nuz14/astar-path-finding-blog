🧭 A* Search on a Grid

Understanding how the A* search algorithm finds an efficient path between two points while avoiding obstacles on a grid.

🌊 Introduction

What is A* Search?

A* (A-star) is a path-finding algorithm used to find a suitable route between a starting point and a target point. It combines the cost of reaching a location with an estimate of the remaining distance to the target.

A* is commonly used when we need to find a path while considering both the distance already travelled and the estimated distance remaining.
🧩 Core Idea

Searching on a Grid

A grid can represent a map or environment. Each cell represents a possible position. Some cells are free while others contain obstacles that cannot be crossed.

The algorithm starts from the source cell and explores possible neighbouring cells until it reaches the destination.

📐 Evaluation Function

The A* Formula

A* evaluates each position using the following function:

f(n) = g(n) + h(n)

g(n) = actual cost from the starting point.

h(n) = estimated cost from the current point to the goal.

f(n) = total estimated cost.

⚙️ Algorithm

How A* Works

1 · Start Begin from the starting cell.
2 · Evaluate Calculate the f, g and h values.
3 · Explore Select the most promising cell.
4 · Reach Goal Continue until the destination is reached.
🚧 Obstacles

Obstacle Avoidance

Obstacles are represented by blocked cells in the grid. A* ignores these cells while searching for a valid route.

This allows the algorithm to find a path around walls and other blocked areas instead of moving directly through them.

💡 Heuristic

Manhattan Distance

For a grid where movement is allowed horizontally and vertically, Manhattan distance can be used as the heuristic.

h(n) = |x₁ - x₂| + |y₁ - y₂|

It estimates how far the current cell is from the target.

🗺️ Example

Simple Grid Example

Suppose the starting point is (1, 1) and the destination is (5, 4). The Manhattan distance is:

h(n) = |1 - 5| + |1 - 4| = 4 + 3 = 7

The algorithm uses this estimated value along with the actual path cost to decide which cell should be explored next.

🌐 Applications

Where is A* Used?

  • Game character navigation
  • Robot path planning
  • Maps and route planning
  • Grid-based simulations
  • Obstacle avoidance systems
✨ Advantages

Benefits of A*

  • Uses both actual and estimated cost.
  • Can avoid blocked areas.
  • Works well on grid-based environments.
  • Can find an efficient path.
  • Useful for many navigation problems.
💙 Conclusion

Key Takeaway

A* Search is an important path-finding algorithm that combines the distance already travelled with an estimated distance to the destination. By considering obstacles and choosing promising paths, it can efficiently solve many grid-based navigation problems.
